# AI Agent Operational Boundaries

This example demonstrates an AI agent designed to operate within clearly defined boundaries. It shows how an agent can process valid inputs, identify issues within its operational scope, and crucially, recognize and report when inputs are outside its expected parameters or malformed, thus 'knowing its limits' and signaling for human intervention rather than making an unreliable decision.

## Language

`python`

## How to Run

Save the code as `main.py`. Open a terminal or command prompt, navigate to the directory where you saved the file, and run: `python main.py`
